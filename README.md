### 📌 Projeto em destaque

**Arctus Solutions — Dashboard de Analytics de Atendimento** *(nome fictício, dados anonimizados conforme LGPD)*

Pipeline completo de dados para operações de suporte, integrando **Office Scripts (TypeScript)**, **Power Automate** e **Power BI** no ecossistema Microsoft 365 — da ingestão de CSVs brutos até um dashboard executivo.


<p align="center">
  <img src="https://raw.githubusercontent.com/igormr/arctus-suporte-analytics/master/assets/dashboard_bi.gif" alt="Dashboard Arctus Solutions" width="800"/>
</p>

**O que o pipeline resolve:**
- Consolidação diária de 4 tipos de relatório (CSV) em uma tabela histórica única, com lógica de *upsert* automática por agente e data
- Detecção automática de tipo de relatório via padrão de nome de arquivo
- Medidas DAX para CSAT, resolução no 1º contato, reabertura e status por agente (Top/Ok/Atenção/Crítico)
- Visualização detalhada por colaborador, com filtros simples para consulta rápida de indicadores individuais
  
🔗 **[Ver repositório no GitHub](https://github.com/igormr/arctus-suporte-analytics)**
